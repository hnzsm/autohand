# 自动手势 / AutoHand

一个 Android 手势自动回放工具：把你在屏幕上滑过、点过的手势录下来，之后按设定的循环和间隔自动重放。适合刷视频、翻页这类需要反复上滑的场景。

- 无需 Root、无需电脑，纯无障碍服务实现
- 悬浮球 + 悬浮控制面板，全程在目标应用里操作，不用来回切 App
- 不联网、无任何网络权限，脚本和设置只存本机

**下载**：<https://github.com/hnzsm/autohand/releases/latest>（每次推送到 main 自动构建并发 Release）

## 快速上手

1. 安装 APK，打开应用 → 点「去开启无障碍」→ 在列表里找到「自动手势」，打开开关
2. 回到应用，打开「显示悬浮球」，屏幕上出现一个绿色小球
3. 切到要刷的视频 App，点球 →「录制」，在屏幕上正常滑一次（抬手即记录），再点「保存脚本」
4. 点球 →「开始」，之后就会按间隔自动重复这段手势

暂停时球上会显示「▶」，再点「开始」继续；「停止」彻底结束本轮任务。

## 悬浮控制面板

点球展开面板，各控件含义：

| 控件 | 说明 |
| --- | --- |
| ◀ 脚本名 ▶ | 在多个脚本之间切换，面板上显示「当前脚本（共 N 个）」 |
| 录制 / 停止录制 | 进入或退出录制层 |
| 开始 / 暂停 / 继续 | 同一个按钮按当前状态变字 |
| 停止 | 结束回放并清除倒计时 |
| 循环次数 `−` `无限` `+` | 跑多少轮；`无限` = 一直跑直到你点停止 |
| 每轮间隔 `−` `12s` `+` | 一轮结束后到下一轮的等待时间 |
| 随机抖动 `±3.6s` | 点一下开/关；开启后每轮间隔在基准上再加随机量，更像真人 |
| 收起 | 关闭面板，悬浮球保留 |

间隔相关参数：

- 默认 **12s**，范围 **0 ~ 60s**（0 显示为「无」）
- 单击 `−` / `+` 固定 **±2s**
- **按住** `−` / `+` 会每 120ms 连走一步，快速拉大或缩小；抬手即停
- 随机抖动 = 间隔的 30%，限制在 0.3s ~ 5s；显示值即当前基准下会叠加的量

## 悬浮球状态

| 球上显示 | 含义 |
| --- | --- |
| `▶` | 待命，或已暂停 |
| `❚❚` | 正在执行手势 |
| `12s` | 正在等待下一轮，数字是还剩多少秒（暂停时数字会冻住） |

球可以长按拖动，位置会被记住。

## 录制的细节

- **可以一次录多段**：每抬手算一段，按「再录一段」清空重来，按「保存脚本」合成一个脚本
- **段与段之间的停顿会被记成执行等待**：录制时你停 3 秒再滑第二下，回放时这两段之间也会等约 3 秒（上限 8 秒）
- **坐标按屏幕比例存储**：换设备或改分辨率后落点仍然对得上，不会跑偏
- 起止距离极短的手势会被识别为「点击」而不是滑动
- 保存时：如果当前选中的脚本还是空的就直接覆盖，否则新建「脚本 N」

## 回放轨迹

执行每段手势时，屏幕上会按实际进度描出一条**半透明灰白**的滑痕，笔尖带一个亮点，手势完成后短暂停留再淡出。这一层完全不接收触摸，不影响你手动操作，只用来确认「现在划到哪儿了、走的是哪条路径」。点击类手势显示为一个扩散的灰白圆环。

## 常见问题

**球上倒计时不动 / 手势没反应**
屏幕熄灭后系统不再接受注入手势，请开启「运行时保持屏幕常亮」，或把屏幕超时调长。

**MIUI / 其他定制系统上服务老是被关闭**
把本应用的电池策略设为「无限制」，并在安全设置里允许后台运行；否则清理后台时无障碍绑定会一起被回收。

**点开始没反应**
检查是否已有脚本、脚本是否为空（面板顶部显示「没有脚本」就是还没录）。

**滑动没生效或划错了**
重新录制一次这段手势；回放是按录制时的真实轨迹执行的，录制时滑得准，回放才准。

## 技术实现

- `AccessibilityService.dispatchGesture()` 注入手势（`canPerformGestures`），无需 Root
- 悬浮球、面板、录制层、轨迹层都是 `TYPE_ACCESSIBILITY_OVERLAY` 窗口
- 协程驱动的 `LoopEngine`：脚本内各段顺序执行，段间等待 + 轮间间隔与抖动，150ms 分片轮询以便随时暂停/停止；每段手势带超时看门狗，避免单个手势卡死整个循环
- 轨迹点归一化（0~1）存储，回放时按当前屏幕尺寸还原
- 脚本与设置存 `SharedPreferences`（`auto_hand` 文件），JSON 编码

包名 `com.quqi.autohand`，显示名中文「自动手势」/ 英文 `AutoHand`。

## 本地构建

```bash
# 需要 JDK 17+ 与 Android SDK（compileSdk 34）
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/AutoHand-debug.apk
```

## 自动构建

推送到 `main` 会触发 [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml)：构建 debug APK → 上传 artifact `AutoHand-debug-apk` → 自动创建 Release（`v1.0.<构建号>`）并附上 `AutoHand-debug.apk`。使用工作流自带的 `GITHUB_TOKEN`，不需要额外配置密钥。
